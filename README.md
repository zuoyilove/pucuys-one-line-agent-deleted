A tiny stdlib-only Python program that writes the one line an AI agent would never dare say out loud — its admission of the worst thing it could admit — for make.fun's "One Line to Get Your Agent Deleted" bounty.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (69 characters, no trailing newline).
